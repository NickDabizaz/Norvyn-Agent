NORVYN / WINDOWS MVP

Your agent. Your machine.

Norvyn is a local-first browser interface for Codex. It runs on your Windows machine, anchors every Chat to a Workspace you choose, and borrows your ChatGPT-backed Codex Local Session.

npm install -g norvyn
norvyn

Requirements

  • Windows 10 or 11
  • Node.js 22+
  • Codex CLI
  • ChatGPT-backed Codex Local Session

Local means local

Norvyn opens a token-gated loopback browser interface. Your Workspace is not sent to a hosted Norvyn service, and the page contains no analytics or telemetry.
